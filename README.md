# Sales Performance Dashboard - Project 1
Live interactive dashboard built from Pretoria

**Limk:** https://github.com/Koketso-tshabalala/Project-1

# What it does
- Analyses SuperStore Sales (5901 orders, 2019-2020)
- KPIs: $1.56M Revenue, $175K Profit, 3003 Orders
- 6 Charts: Regio, Category, Monthly Trend, Top 5 & Low 5 Products

# Built with
Python, Pandas, Streamlit, Plotly

#How to run
pip install streamlit pandas plotly openpyxl
streamlit run dashboard.py

#Insight
-West region leads
-Office Supplies 41.1% of sales
-Dec 2020 peak: $150K
